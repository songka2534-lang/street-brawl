# Street Brawl — ศึกถนนสองเรา

เกมต่อยตีเลื่อนฉากแบบพิกเซลอาร์ต เล่นคนเดียว หรือเล่นออนไลน์ 2 คนผ่านรหัสห้อง เล่นบน iPhone ผ่าน Safari ได้

## วิธีเล่น
- **ตี**: กดรัวได้ 4 จังหวะ จังหวะสุดท้ายเตะจนศัตรูล้ม
- **โดด** แล้วกด **ตี**: กระโดดเตะ
- **อาวุธ**: เดินทับไม้เบสบอลหรือท่อเหล็กเพื่อเก็บ กด **ตี** เพื่อฟาด กด **จับ** เพื่อขว้าง
- **กลิ้งหลบ**: โยกจอยลงค้างไว้แล้วกด **โดด**
- **ยั่ว**: ตอนไม่มีศัตรูใกล้ กด **จับ** ค้างไว้ เติมแถบ Super
- **จับ**: ยืนชิดศัตรูแล้วกดจับ จากนั้นกด **ตี** เพื่อเข่า หรือกด **จับ** อีกครั้งเพื่อทุ่ม
- **หมุน**: เตะหมุนพายุ กวาดศัตรูทั้งซ้ายและขวา แลกกับเลือดเล็กน้อย
- **พิเศษ**: เตะพุ่งแลกกับเลือดเล็กน้อย ถ้าแถบสีเหลืองเต็ม จะเป็นท่า **SUPER BLAST** ที่กวาดทั้งจอ
- คีย์บอร์ด: ลูกศรหรือ WASD เดิน · J ตี · K โดด · L จับ · I พิเศษ · U หมุน · Esc หยุดเกม

## ตัวละคร
- **มายา** (หญิง): เร็ว กระโดดสูง
- **ไค** (ชาย): ช้ากว่า แต่ตีแรงและเลือดเยอะกว่า

เลือกตัวได้ก่อนเล่นคนเดียว หรือในห้องรอตอนเล่นออนไลน์ ถ้าเลือกตัวเดียวกัน ผู้เล่น 2 จะได้สีชุดต่างกัน

## ด่าน
1. ถนนร้านพิซซ่า (ตอนเย็น)
2. ตลาดนัดกลางคืน
3. ท่าเรือคืนฝนตก
4. ดาดฟ้าตึกในหมอก
5. รถไฟฟ้าไฟดับ

ฉากแบบตลาด ท่าเรือ ดาดฟ้า และรถไฟฟ้ามีเฉพาะเวอร์ชัน 3D (ใส่ `theme` ใน `STAGES`) ส่วนเวอร์ชัน 2D ใช้ฉากถนนแต่เปลี่ยนบรรยากาศ

## เล่นออนไลน์
1. คนแรกกด **เล่นออนไลน์กับแฟน → สร้างห้อง** แล้วส่งรหัส 4 หลักให้อีกคน
2. อีกคนกด **เข้าห้อง** แล้วใส่รหัส
3. คนสร้างห้องกด **เริ่มเกม** ถ้าเน็ตหลุด กดเข้าห้องด้วยรหัสเดิมได้เลย

ใช้ WebRTC ผ่าน PeerJS เครื่องของคนสร้างห้องเป็นตัวคำนวณเกม

## เพิ่มด่านใหม่
แก้แค่ `js/data.js` โดยเพิ่ม object ใหม่ต่อท้ายใน `STAGES`
- `len`: ความยาวด่าน
- `mood`: `dusk` / `night` / `rain` / `fog` / `dark`
- `seed`: ตัวเลขสำหรับสุ่มหน้าตึก
- `barrels`: ตำแหน่งถังน้ำมัน
- `waves`: ระลอกศัตรู ระลอกสุดท้ายใส่ `at: 'end'` และใส่ `boss`

## เวอร์ชัน 3D และ 2D
เป็นหน้าหลัก (`index.html`) ส่วนเวอร์ชัน 2D อยู่ที่ `2d.html` สำหรับมือถือรุ่นเก่า ระบบเกม ด่าน และโหมดออนไลน์เหมือนเวอร์ชัน 2D ทุกอย่าง ต่างกันแค่ภาพ
ตัวละคร 3D ของ Quaternius ใช้สัญญาอนุญาต CC0 (ดู `assets/3d/LICENSE.txt`) วาดภาพด้วย Three.js (MIT)
