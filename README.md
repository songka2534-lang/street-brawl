# Street Brawl — ศึกถนนสองเรา

เกมต่อยตีเลื่อนฉากแบบพิกเซลอาร์ต เล่นคนเดียว หรือเล่นออนไลน์ 2 คนผ่านรหัสห้อง เล่นบน iPhone ผ่าน Safari ได้

## วิธีเล่น
- **ตี**: กดรัวได้ 3 จังหวะ จังหวะสุดท้ายเตะจนศัตรูล้ม
- **โดด** แล้วกด **ตี**: กระโดดเตะ
- **จับ**: ยืนชิดศัตรูแล้วกดจับ จากนั้นกด **ตี** เพื่อเข่า หรือกด **จับ** อีกครั้งเพื่อทุ่ม
- **พิเศษ**: เตะพุ่งแลกกับเลือดเล็กน้อย ถ้าแถบสีเหลืองเต็ม จะเป็นท่า **SUPER BLAST** ที่กวาดทั้งจอ
- คีย์บอร์ด: ลูกศรหรือ WASD เดิน · J ตี · K โดด · L จับ · I พิเศษ · Esc หยุดเกม

## เล่นออนไลน์
1. คนแรกกด **เล่นออนไลน์กับแฟน → สร้างห้อง** แล้วส่งรหัส 4 หลักให้อีกคน
2. อีกคนกด **เข้าห้อง** แล้วใส่รหัส
3. คนสร้างห้องกด **เริ่มเกม** ถ้าเน็ตหลุด กดเข้าห้องด้วยรหัสเดิมได้เลย

ใช้ WebRTC ผ่าน PeerJS เครื่องของคนสร้างห้องเป็นตัวคำนวณเกม

## เพิ่มด่านใหม่
แก้แค่ `js/data.js` โดยเพิ่ม object ใหม่ต่อท้ายใน `STAGES`
- `len`: ความยาวด่าน
- `mood`: `dusk` / `night` / `rain`
- `seed`: ตัวเลขสำหรับสุ่มหน้าตึก
- `barrels`: ตำแหน่งถังน้ำมัน
- `waves`: ระลอกศัตรู ระลอกสุดท้ายใส่ `at: 'end'` และใส่ `boss`
